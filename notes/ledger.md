# Ledger

Lessons for sessions in this repository. Every rule names what enforces it.

| Date | Rule | Enforced by |
|---|---|---|
| 2026-09-30 | A change under examples/ regenerates the render fixtures under crates/stencil-render/tests/fixtures and runs cargo test --workspace before the PR opens. stencil check on the changed figure is not verification of the repository. | .github/workflows/ci.yml on every pull request; `mise run land -- <pr>` waits for the checks and squash-merges, so the conventional PR title becomes the commit subject (the repository allows squash merges only; branch protection is unavailable on this private repository) |
| 2026-09-30 | In an iso figure, a zone edge through label text is a check defect, not a note for visual review; labels move to open floor before the check runs. | `iso-labels-clear` slab-edge pairs in crates/stencil-render/src/iso.rs, tested in crates/stencil-render/tests/iso.rs; `stencil gallery` fails on any example whose own projection is iso |
| 2026-09-30 | In an iso figure, a link leg within 24 px of a parallel zone edge, a leg that turns back, or a last leg shorter than two arrowheads is a check defect, not a note for visual review. | `iso-links-clear` in crates/stencil-render/src/iso.rs, tested in crates/stencil-render/tests/iso.rs; `stencil gallery` fails on any example whose own projection is iso |
| 2026-10-01 | `gh pr merge --delete-branch` switches the local checkout to main after the merge, which fails whenever main is held by another worktree, so the land task reports failure on a PR that did merge. The repository deletes head branches on merge by itself. | mise.toml `land` task runs `gh pr merge --squash` with no `--delete-branch`; repository setting `delete_branch_on_merge` |
| 2026-10-01 | Under iso a tag, a label or any part placed from a route must read the drawn route, not the layout route: rule 8 and the slab exit move legs after layout, and a tag kept on the layout leg sat 14 px off the wire while every check passed. | `the_hero_primary_tag_lies_on_its_drawn_leg` in crates/stencil-render/tests/iso.rs |
| 2026-10-01 | A floor plan needs more than proportional padding: growing the type under iso without growing the paddings leaves names hugging the slab edges. Spacing under iso is its own scale (`ISO_SPACE_SCALE`), judged on the hero before fixtures move. | the hero fixtures and docs/gallery/hero-iso.png, byte-checked in CI; design renders judged under .agents/research in the dp monorepo |
| 2026-10-02 | A vertical riser at a slab edge is only right on a face the viewer sees. At a back or left edge the ground piece is drawn across the slab top for one step of height and then climbs, which reads as a hook; the ground piece ends where it passes under the top edge on screen and the pen lifts to the top piece. | `a_path_passes_under_a_hidden_edge_and_climbs_a_visible_one` in crates/stencil-render/src/iso/drape.rs; `a_link_between_two_zones_steps_down_to_the_ground_and_back_up` and `a_dashed_link_skips_its_risers_and_a_solid_one_draws_them` in crates/stencil-render/tests/iso.rs |
| 2026-10-02 | A pipe under iso is a tube, not a line: a wire drawn as a stroke reads as a floor marking next to raised solids, and the flat dot ellipse at its end is the wrong primitive once the ends carry rings and cones. The tag then lies on the tube top, not the floor. A non-required status check (Aikido code coverage) left pending stalls `mise run land`, whose watch covers every check. | `pipes_are_tubes_with_their_tags_on_top` in crates/stencil-render/tests/iso.rs; unit tests in crates/stencil-render/src/iso/tube.rs; the onprem-iso center fixture; land task to watch required checks only (follow-up PR) |
| 2026-10-02 | `gh pr checks --watch` waits on every check, and an optional check that never reports (Aikido code coverage) stalls the merge for good; `--required` would watch only the one required check and skip the CI jobs. The land task watches the ci.yml run for the head commit and then merges. | scripts/land.sh, run by the `land` task in mise.toml |
| 2026-10-02 | An icon-less kind needs its own default shape, or every person and device falls back to a card: the shape lookup reads the item, then the icon row, then the kind. A sprite is composed from the box and round primitives the shapes already draw, so its outline, shadow and link cut-back come for free. | `gcp_has_a_product_kind_with_every_icon_once_in_icon_order_and_a_person_and_a_device` and `plain_has_four_containers_and_five_icon_free_items` in crates/stencil-model/tests/grammar.rs; unit tests in crates/stencil-render/src/iso/sprites.rs; the people-iso center fixture |
| 2026-10-02 | A band is a Pipe form, not a Link style: a Pipe already owns a row-spanning slot with a direction, arrow ends and target centering, which is what a wide floor arrow across a row needs; a Link is routed and cannot be wide across a row. The projection must know the form, carried on the layout node like an item shape, or the tag lands on a tube top that is not there. | `a_band_pipe_lies_flat_with_its_tag_on_the_floor` in crates/stencil-render/tests/iso.rs; `a_band_lies_flat_on_its_plane_with_a_wide_head` in crates/stencil-render/src/iso/tube.rs; the onprem-iso center fixture |
| 2026-10-02 | An approach stub of a fixed length starts the route search inside a neighbour when the gap is smaller than the stub, and the search then has no way out: a link over two row neighbours fell back to a straight line through them. The stub stops at the nearest obstacle ahead of it. | `an_iso_link_over_two_row_neighbours_routes_around_them` in crates/stencil-layout/tests/links.rs |
| 2026-10-02 | A zone label reserve sized for a card hides the label behind any taller solid in the first row: the reserve is the tallest shape among the zone's items plus the clearance. A Tee hub pill between two raised arm tags needs the tag clearance on both sides under iso. | `iso-labels-clear` on examples/transit-iso.json (check fixture); the transit-iso center fixture |
